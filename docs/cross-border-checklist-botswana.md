# Cross-Border Documentation Checklist — Botswana

Requirements specific to the Skilpadshek/Pioneer Gate and Groblersbrug/Martin's Drift crossings, supplementing the
Cross-Border Documentation Checklist — Overview.

## 1. Import documentation required by BURS

- Customs declaration, lodged through the Botswana Unified Revenue Service's electronic system by Baobab's
  Gaborone clearing agent
- Commercial invoice and packing list
- SACU status documentation — because South Africa and Botswana are both SACU members, standard SACU-origin goods
  typically move without additional duty, but import VAT and administrative clearance still apply and still require
  a declaration

## 2. Vehicle documentation

- Temporary Import Permit for the vehicle combination
- Cross-Border Road Transport Agency permit (see the Overview document — this is a Baobab fleet-level requirement,
  already held)
- Third-party insurance valid in Botswana

## 3. Permit-controlled categories

Livestock, meat, and plant/agricultural material require veterinary or phytosanitary certification issued in
advance by Botswana's Ministry of Agriculture, and are subject to physical inspection at the border. These
shipments should be booked with an extended lead time and are excluded from the standard SLA transit guarantee.

## 4. Choosing the crossing point

Skilpadshek/Pioneer Gate is used for Gaborone and southern/central Botswana destinations; Groblersbrug/Martin's
Drift is used for Francistown and northern Botswana destinations, including onward transit toward Zambia via the
Kazungula crossing for clients with combined Botswana/Zambia routing needs. Baobab's booking system selects the
crossing automatically based on final destination.

## 5. Common documentation errors on this corridor

Declared value discrepancies between the commercial invoice and the value stated on the customs declaration are the
most common cause of query at BURS clearance. Clients should ensure the invoice used for the Botswana declaration
matches the invoice used for the South African export declaration exactly.
