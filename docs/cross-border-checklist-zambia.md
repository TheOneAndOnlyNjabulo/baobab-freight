# Cross-Border Documentation Checklist — Zambia

Requirements specific to the Zambia corridor, which transits Zimbabwe via Beitbridge and crosses into Zambia at
Chirundu. Supplements the Cross-Border Documentation Checklist — Overview and the Zimbabwe checklist (since this
corridor also requires Zimbabwean transit documentation).

## 1. Import documentation required by ZRA

- ASYCUDA World electronic customs declaration, lodged by Baobab's Lusaka clearing agent
- Commercial invoice and packing list
- Certificate of Origin, where a SADC preference is claimed
- Import permit, for controlled categories (mining equipment concessions, agricultural inputs — see section 3)

## 2. Zimbabwean transit documentation

Because this route transits Zimbabwe, a Zimbabwean transit bond (or carnet, depending on cargo type) is required in
addition to the standard documentation. Baobab arranges the transit bond as part of the standard Zambia corridor
booking — clients do not need to arrange this separately, but should be aware it is why Zambia corridor bookings
require slightly longer lead time to prepare than a direct single-border corridor.

## 3. Permit-controlled categories and incentive schemes

Mining and copperbelt-industry equipment (common on this corridor given Zambia's copper mining sector) may qualify
for duty rebates under Zambian investment incentive schemes, subject to the client holding a valid investment
certificate issued by the Zambia Development Agency. Clients should provide this certificate at booking if claiming
the rebate, as it cannot be applied retroactively after clearance.

## 4. Chirundu one-stop border post

Chirundu processes both Zimbabwean export and Zambian import formalities at a single facility, which generally
reduces total border time compared to older dual-post crossings on other corridors. Standard clearance allowance at
Chirundu is built into the Zambia corridor's published transit times in the Delivery SLA Policy — Zambia Corridor
document.

## 5. Common documentation errors on this corridor

Because this route involves two separate customs administrations (Zimbabwe transit, then Zambia import), the most
common error is submitting documentation sufficient for Zimbabwean transit but incomplete for Zambian import (e.g.
missing the ASYCUDA declaration components ZRA requires). Baobab's brokerage team checks both document sets before
the consignment departs South Africa.
